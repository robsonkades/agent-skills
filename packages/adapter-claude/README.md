# @jvm-expert/adapter-claude

Claude Code adapter for agent-skills.

Part of [agent-skills](https://github.com/robsonkades/agent-skills), a package manager for AI
coding-agent skills. Most people want the CLI:

```bash
npx @jvm-expert/agent-skills install java-performance
```

Installs to `\/skills` globally and `.claude/skills` per project, and projects
the neutral package format onto the frontmatter Claude Code reads.
