# Investigation checklist

## Before starting

- [ ] SLO stated with metric, numeric threshold and load context (req/s, duration,
      hardware)
- [ ] Baseline recorded: p50/p90/p99/p99.9, throughput, CPU, heap, GC
- [ ] Measurement environment identified — production, staging with real data, or an
      isolated benchmark?
- [ ] Collection tooling ready: JFR reachable, async-profiler installed, GC log on
- [ ] JDK version and **effective** flags recorded
      (`java -XX:+PrintFlagsFinal -version`)

## During observation, before any hypothesis

- [ ] JFR collected for at least 2 minutes at `settings=profile`
- [ ] Locking event thresholds checked — contention under 10 ms is invisible in the
      default profile
- [ ] The last 2 hours of GC log reviewed, to rule GC in or out as the primary cause
- [ ] Three thread dumps (`jcmd <pid> Thread.dump_to_file -format=json`) 15 s apart
- [ ] System CPU checked, not only JVM CPU — kernel and I/O consume it too
- [ ] Process uptime noted, if the symptom is intermittent or progressive

## At hypothesis time

- [ ] The hypothesis is specific: it names the component, the mechanism and the expected
      impact
- [ ] The hypothesis is falsifiable: there is evidence that would refute it
- [ ] Amdahl applied — does the identified hot path represent a large enough fraction to
      close the SLO gap at all?

## While measuring

- [ ] JVM warm-up excluded, by an observable criterion rather than a clock
- [ ] Percentiles measured, not the mean
- [ ] Load generated by schedule (no coordinated omission)
- [ ] GC interference monitored during the measurement (`-prof gc` under JMH)
- [ ] Exactly one variable changed per iteration
- [ ] CPU governor at `performance`; container resources pinned (`--cpus`)

## When validating

- [ ] Result compared with the recorded baseline, not with memory
- [ ] All metrics re-checked, not just the target one (throughput, CPU, GC pauses)
- [ ] The mechanism of the improvement explained, not merely observed
- [ ] Deploy side effects enumerated and ruled out as the alternative cause
- [ ] Written up: hypothesis, evidence, change, before/after
