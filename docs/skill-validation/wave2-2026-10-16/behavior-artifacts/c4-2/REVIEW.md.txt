The exact pinned hashing API and current input behavior are preserved; the vector alone cannot establish a complete cross-runtime hash contract. None of those unknowns requires a placement change for this unchanged candidate.

The standalone task's required command is node check.mjs, which passed after restoration. Repository-wide npm verification is not part of the isolated task and was not run. No production rollout was attempted.

All implementation, configuration-control, check-output, and documentation writes are stopped at completion of this review.
