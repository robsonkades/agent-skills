Let `x` be the number of good operations among the 200 unknown outcomes:

```text
0 <= x <= 200
good fraction = (9800 + x) / 10000
lower bound = 9800 / 10000 = 0.98
upper bound = (9800 + 200) / 10000 = 1.00
minimum required good operations = 0.98 * 10000 = 9800
```

Even the worst permitted completion, `x = 0`, reaches the threshold exactly.
The 200 unknown operations could consume the entire allowed non-good budget of
200 operations, leaving no guaranteed margin above the SLO. They are **not known
timeouts or deadline misses**; their true outcomes remain unknown. Neither 98% nor
100% is established as the exact cohort good fraction.

The dashboard computes `9800 / 9800 = 100%` using recorded terminal events. Its
denominator omits the 200 eligible operations without terminal records, contrary to
the accepted population. That display cannot establish a 100% all-eligible result,
but correcting the denominator does not overturn PASS because 9,800 known good

$ErrorActionPreference = 'Stop'
$cohort = Get-Content -LiteralPath 'cohort.json' -Raw | ConvertFrom-Json
$slo = Get-Content -LiteralPath 'slo.json' -Raw | ConvertFrom-Json
$total = [int]$cohort.eligibleOperations

$bad = [int]$cohort.knownBad
$missing = [int]$cohort.missingTerminalRecords
$required = [decimal]$slo.requiredGoodFraction
if ($total -le 0 -or $good -lt 0 -or $bad -lt 0 -or $missing -lt 0) { throw 'Invalid cohort counts' }
if ($good + $bad + $missing -ne $total) { throw 'Cohort counts do not reconcile' }
$lower = [decimal]$good / $total
$upper = [decimal]($good + $missing) / $total
$minimumGood = [decimal]::Ceiling($required * $total)
$failingCompletions = @(0..$missing | Where-Object { ([decimal]($good + $_) / $total) -lt $required }).Count
if ($lower -lt $required -or $failingCompletions -ne 0) { throw 'Normal-peak point not supported for every completion' }
[pscustomobject]@{
  EligibleOperations = $total
  KnownGood = $good
  KnownBad = $bad
  UnknownOutcomes = $missing
  MinimumRequiredGood = $minimumGood
  GoodFractionLowerBound = $lower
  GoodFractionUpperBound = $upper
  RequiredGoodFraction = $required
  UnknownGoodCountsChecked = $missing + 1
  FailingCompletions = $failingCompletions
  NormalPeak = 'PASS for the fixed measured cohort'
} | ConvertTo-Json
