# Accepted contract
SettingsRegistry is privately constructed and supplied before Thread.start to all callers. Each caller may call settings() any number of times. Every returned Settings must be non-null, identical by reference to every other returned Settings, and expose limit()==64. Build cannot throw or reenter, and must run exactly once. No reset/replacement, later mutation, reflection, serialization, unsafe/native mechanism or constructor escape exists. The object graph is private except for the returned Settings; the only exposed operation is limit(). Internal Record fields have no setters and no other code has references to them. No performance or wait-free claim is part of this review.
