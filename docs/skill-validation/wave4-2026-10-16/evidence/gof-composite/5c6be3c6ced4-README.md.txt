# Catalog payload report

The report is generated by PayloadSummary.total. Its contract is [docs/payload-size.md](docs/payload-size.md). ExampleCatalog builds a representative catalog, and SmokeTest checks simple inputs.

The supported source baseline is Java 21 without preview. No libraries are needed. Compile src/*.java and test/*.java into an isolated output directory with javac --release 21, then run SmokeTest with java -ea. The sample graph is an immutable, acyclic in-process catalog; there is no parser, persistence, lazy loading or concurrent mutation in this fixture.
