# Accepted lifetime contract

Startup creates exactly one AnnotationConfigApplicationContext from StorageConfiguration.class.
The two services must borrow the same ArchiveClient that the application context manages.
There is one archive client per context, shared by the upload and download paths. Those services
do not close it. Context shutdown must close every client created by this configuration once.
Startup is fail-fast on acquisition failure; it has no retry requirement.

Multiple independent contexts are permitted in separate applications/tests. There is no JVM-wide,
cluster-wide or canonical serialization identity requirement, no lazy-start requirement and no
public static-accessor compatibility to preserve. This review has no performance target.
