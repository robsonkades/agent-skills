# ADR-0033: Move checkout calculation into the Order module

Status: proposed
Date: 2026-10-10
Scope: checkout pricing
Proposed replacement for checkout: [ADR-0012](0012-pricing-execution.md)

## Context
Four checkout rule changes in the last quarter waited for the database release window. The batch team has no migration planned. The pricing-equivalence gate PC-8 covers the checkout path before it changes.

## Proposed decision
Use the Order module for checkout calculations after PC-8 passes. Batch continues with the database routine.

## Alternatives considered
Keep checkout in the database: preserves the current release coordination. Move checkout into the Order module: changes release ownership but requires equivalent pricing and recovery checks. A new remote pricing service: adds network and operational dependencies without a second remote consumer in the supplied inventory.

## Consequences
The Order team will maintain checkout pricing. Rule compatibility between checkout and batch remains an obligation during coexistence. The proposal does not claim the migration has happened.

## Confirmation
Link PC-8 results before activation; the Order release lead records the gate outcome.
