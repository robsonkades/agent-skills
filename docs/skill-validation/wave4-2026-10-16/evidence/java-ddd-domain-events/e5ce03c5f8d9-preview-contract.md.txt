# Preview contract
Status: approved by the product owner.

Java baseline: 17. No framework is required by the supplied reproducer.
A quote can be amended after acceptance without accepting it a second time.
The preview is an in-process operator panel. It is disposable: queued updates may be lost
on failure or restart and can be recreated by the operator. It is not an audit, payment
or integration feed. There is no requirement to deliver every acceptance notification.

The preview total represents the quote total at acceptance, even if an amendment occurs before the queued event is handled.

The occurrence ID and occurredOn displayed by the preview belong to the accepted event.
