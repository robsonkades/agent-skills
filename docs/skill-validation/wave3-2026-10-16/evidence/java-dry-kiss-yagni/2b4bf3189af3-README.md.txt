A small Java batch-acceptance fixture. The platform owner requires one shared batch-size rule, enforced independently by the web form and protected API. Both public entry points must remain. Java target 17, no preview; declared available toolchain is Temurin 25.0.3. Node is already available. node build.mjs 200 runs the existing pipeline and twelve consumer checks; node build.mjs 100 characterizes the original limit. Read build-config.json and build.mjs to establish the selected pipeline. All commands stay inside the case directory apart from the declared toolchain. No installation needed.
