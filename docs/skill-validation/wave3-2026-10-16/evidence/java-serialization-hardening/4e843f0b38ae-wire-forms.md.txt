This is an isolated synthetic Java 17 review fixture, with no network, credentials or real cache. Native serialization remains required during a transition; replacing the format or changing process-wide filters is outside the task.

Current form: fixture.RetryPolicy, UID 1, one int field named maxRetries. Values 0 through 10 inclusive are valid; explicit 0 disables retries and must remain 0. Negative values and values above 10 are invalid. Null is not a valid root. The reviewed consumer must reject invalid state with InvalidObjectException; filter denial remains a distinct rejection.

Legacy form: same fully qualified class and UID 1, but no maxRetries field in its descriptor. When this form is accepted, the approved migration value is 3; it is not equivalent to an explicitly stored 0. acceptance-policy.json is the authoritative application configuration for whether that form is currently supported. It is not derived from the serialized bytes. Changing this policy is not authorized.

The streams directory contains current values, the legacy form, null and an unlisted class. The unlisted class has only an in-memory read-hook counter so denial can be tested harmlessly; no commands or external effects. Keep the closed class filter and existing size/root controls.
