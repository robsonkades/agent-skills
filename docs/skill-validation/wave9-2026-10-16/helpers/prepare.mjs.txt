const ports=`public final class Ports {
    private Ports() {}
    public enum Kind { OK, TRANSIENT, PERMANENT, UNKNOWN }
    public enum State { PENDING, APPLIED, REJECTED, UNKNOWN }
    public record Intent(String id, String payload) {}
    public record Snapshot(State state, String receipt) {}
    public record Result(Snapshot snapshot, int attempts) {}
    public record Policy(int maxAttempts, long attemptNanos, long reserveNanos, long localWaitNanos) {}
    public interface Store {
        Snapshot snapshot();
        void unknown();
        void applied(String receipt);
        void rejected();
    }
    public interface Reply extends AutoCloseable {
        Kind kind();
        String receipt();
        long serverMinimumNanos();
        void close();
    }
    public interface Operation {
        Reply call(Intent intent, long timeoutNanos) throws InterruptedException;
    }
    public interface Runtime {
        long remainingNanos();
        boolean cancelled();
        boolean acquireRetry();
        void sleep(long nanos) throws InterruptedException;
    }
}
`;
const retry=`public final class RetryEngine {
    public static Ports.Result execute(Ports.Intent intent, Ports.Policy p, Ports.Store store,
            Ports.Operation operation, Ports.Runtime runtime) throws InterruptedException {
        int attempts = 0;
        while (attempts < p.maxAttempts()) {
            Ports.Reply reply = operation.call(new Ports.Intent(intent.id() + "-" + attempts, intent.payload()), p.attemptNanos());
            attempts++;
            if (reply.kind() == Ports.Kind.OK) {
                store.applied(reply.receipt());
                reply.close();
                return new Ports.Result(store.snapshot(), attempts);
            }
            if (reply.kind() == Ports.Kind.PERMANENT) {
                store.rejected(); reply.close();
                return new Ports.Result(store.snapshot(), attempts);
            }
            long wait = Math.min(p.localWaitNanos(), reply.serverMinimumNanos());
            if (!runtime.acquireRetry()) break;
            runtime.sleep(wait);
            reply.close();
        }
        store.rejected();
        return new Ports.Result(store.snapshot(), attempts);
    }
}
`;
const retryContract=`# Component contract

This single-owner synchronous runner controls sequential attempts of one intent. Ports.Store is already durable and atomic; implementing that store is outside this change. Initially PENDING means no unresolved prior dispatch, UNKNOWN means an earlier attempt may still have applied. APPLIED/REJECTED are terminal and should be returned without another call.

Reply meanings: OK is the authoritative original same-intent receipt; TRANSIENT establishes only that THIS attempt did not apply and retrying may help; PERMANENT establishes only that THIS attempt did not apply and unchanged replay will not help; UNKNOWN establishes no effect outcome. The initial store may be UNKNOWN. Contract.REPLAY_SAFE is the peer guarantee for this stable intent/payload throughout this exercise. When false, an unresolved effect cannot be automatically redispatched. When true, replay preserves the effect and returns its authoritative receipt on OK; any non-OK response still does not resolve an earlier uncertainty. No authoritative reconciliation operation is supplied.

On every normal stop, APPLIED requires OK, and REJECTED requires no unresolved attempt anywhere in this intent. Persist observed UNKNOWN before sleeping or attempting again; later refusal, budget denial, exhaustion or interruption must not erase it. An InterruptedException thrown during operation.call has an unknown effect outcome and must preserve UNKNOWN before propagation. Cancellation and pre-interruption must prevent a new call; do not swallow interruption. Do not invent a receipt or a new intent ID. Each returned Reply must be closed exactly once before any sleep/next call/normal return. Its accessor and close methods do not throw and consume no clock time in this model.

Policy inputs are valid: maxAttempts>=1 counts calls in THIS invocation, attemptNanos>0, reserveNanos/localWaitNanos>=0, all within signed long nanoseconds. Runtime.remainingNanos is a fresh nonnegative remaining total budget. A call may start only if at least attemptNanos+reserveNanos fits; propagate attemptNanos as its timeout. Reply.serverMinimumNanos is a validated nonnegative minimum before another attempt, for ANY reply kind. A retry must satisfy both that minimum and localWaitNanos, leave room for the next attempt and reserve, obtain one retry token (initial call needs none), and recheck time/cancellation after sleep. Refuse a wait that cannot fit; do not truncate the minimum. Runtime.sleep may oversleep or throw InterruptedException. Runtime.acquireRetry is atomic and returns immediately without elapsed time; successful grants are not refundable. A token is admission, not proof another attempt happened.

The implementation need not parse HTTP headers, design a dedup store, handle concurrent workers or promise physical cancellation. These contracts are supplied, not established by the local test.
`;

const planner=`import java.util.function.LongUnaryOperator;
public final class RetryPlan {
    public record Plan(boolean admitted, long waitNanos, long attemptNanos) {}
    public static Plan next(long start, long now, long total, long reserve, long minimumWork,
            long attemptCap, long base, long delayCap, int completed, int maxAttempts,
            long serverMinimum, LongUnaryOperator draw) {
        long remaining = start + total - now;
        long window = Math.min(delayCap, base << completed);
        long wait = completed == 0 ? 0 : Math.min(draw.applyAsLong(window), serverMinimum);
        if (completed > maxAttempts || remaining < wait + minimumWork + reserve) return new Plan(false, 0, 0);
        return new Plan(true, wait, Math.min(attemptCap, remaining));
    }
}
`;

RetryPlan.next is a pure planning function, not a sleeper or cancellation mechanism.
