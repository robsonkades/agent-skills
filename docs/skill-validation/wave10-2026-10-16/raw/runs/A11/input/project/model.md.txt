# Modelo aceito pelo responsável Bruno
L e M atendem todas as obrigações, incluindo transição. Os dois critérios que restaram são esforço operacional e tempo para entregar mudanças. Para cada critério há uma escala de valor 0–100 calibrada com Bruno; diferenças de valor são significativas dentro de cada escala. Interações de preferência e dupla contagem foram revisadas; Bruno aceita a forma aditiva V = w*operacao + (1-w)*mudanca. Os valores já incluem os custos relevantes. São preferências, não porcentagens de desempenho. Não é necessário substituir o modelo por outro para esta decisão.
